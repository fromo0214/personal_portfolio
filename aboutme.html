About Me

Hi, I’m Fernando Romo — a full-stack software developer based in Los Angeles County. I build clean, user-focused applications across web and iOS, with a strong emphasis on performance, usability, and thoughtful design.

As a first-generation college graduate, I’m highly motivated by continuous learning and taking ownership of projects from concept to deployment.

I develop full-stack applications using Java (Spring Boot), Python, and modern web technologies, and I am currently building iOS applications using Swift and SwiftUI.

My recent work involves deisgning user interfaces in SwiftUI, implementing authentication and data storage, and connecting frontends to scalable backends. I enjoy working across the entire stack — from UI and state management to APIs and databases.
